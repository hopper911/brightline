# Digital project publishing guide

## Before publish

- [ ] Accurate status (never call a concept a Live Product)
- [ ] No invented metrics
- [ ] No TODO text in public fields
- [ ] Cover + alt intent clear
- [ ] SEO title/description filled
- [ ] Mobile review of long screenshots

## Publish order (production)

1. Admin content ready, projects still unpublished or section Hidden
2. Enable section (`enabled`) — direct URL works for published only
3. Turn on `showInNav`
4. Turn on `showOnHome` / about / footer as needed
5. Confirm sitemap entries after deploy

## Unpublish / rollback

- Uncheck Published on the project, or
- Set Design section to Hidden (all public design routes 404; nav removed)
